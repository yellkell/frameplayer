Frame WebXR check

Checks the Steam Frame Chromium build: immersive VR, the valve-frame controller layout, and that Menu doesn't end the session.

  1. Press every control on both controllers: triggers, grips, stick clicks, A B X Y, D-pad, shoulders, view, menu. Roll both sticks round.
  2. Press Menu at least once: the session should keep running.
  3. To finish, hold both triggers and both grips for 2 seconds (or use the Steam button).
