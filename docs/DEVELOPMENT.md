# Developing FramePlayer

## Layout

| Crate | Purpose |
|---|---|
| `fp-core` | Shared types: formats and detection, view settings, sources, playback status |
| `fp-ffmpeg-sys` | Bindings to the bundled FFmpeg 7.1 (per-arch, generated by `tools/gen-ffmpeg-bindings.sh`) |
| `fp-media` | Demux/decode (V4L2 hardware, dav1d), A/V clock, audio out (ALSA), subtitles, thumbnails |
| `fp-render` | Vulkan renderer: projection shader for every format, egui panels, quads |
| `fp-xr` | OpenXR session (direct runtime loading), input, haptic pulses, passthrough |
| `fp-library` | SQLite library: scanning, metadata worker, thumbnails, search, history |
| `fp-sources` | Local, HTTP, WebDAV, DLNA, DeoVR/HereSphere and SMB sources |
| `fp-haptics` | Funscript parsing, sync engine, TCode/Buttplug/Handy devices |
| `fp-remote` | DeoVR remote API and the phone web remote |
| `fp-updater` | Signed update manifests, safe install/rollback; `fp-release` tool |
| `frameplayer` | The app: XR loop, UI, wiring |
| `frameplayer-install` | PC-side installer over SSH |
| `frame-probe` | Milestone 0 platform probe |

## Build and test

```
tools/build-ffmpeg.sh x86_64 aarch64     # once: FFmpeg + dav1d into third_party/
export LD_LIBRARY_PATH=$PWD/third_party/ffmpeg/x86_64/lib
cargo test --workspace                   # GPU tests use any Vulkan device (lavapipe is fine)
tools/package.sh                         # release zip + manifests for the Frame in dist/
```

Needs Rust 1.89+, meson, ninja, nasm, pkg-config, zig (`pip install
ziglang`) and `cargo-zigbuild`. Binaries target glibc 2.28.

## Running without a headset

`--preview` renders offscreen with a simulated head and right controller,
driven by a script, and saves screenshots (see `crates/frameplayer/src/preview.rs`
for the commands):

```
cat > /tmp/demo.fps <<'X'
wait 2
point main 0.24 0.04     # Library tab
click
shot library
open ~/Videos/clip_180_LR.mp4
wait-playing 20
shot playing
X
VK_ICD_FILENAMES=/usr/share/vulkan/icd.d/lvp_icd.json \
  cargo run -p frameplayer -- --preview /tmp/shots --script /tmp/demo.fps
```

With a real OpenXR runtime, e.g. Monado's simulated headset:

```
XRT_COMPOSITOR_NULL=1 SIMULATED_ENABLE=1 monado-service &
XR_RUNTIME_JSON=/usr/share/openxr/1/openxr_monado.json \
  cargo run -p frameplayer -- --exit-after 10 video.mp4
```

## Releasing

1. Once: `fp-release keygen`, paste the printed public key into
   `crates/fp-updater/src/lib.rs` (`RELEASE_PUBLIC_KEY`), and store the
   whole `.key` file as the `FP_RELEASE_KEY` repository secret. Keep the key
   offline otherwise.
2. Bump `version` in `crates/frameplayer/Cargo.toml`, tag `vX.Y.Z`, push.
   CI builds, packages, signs `manifest.json` and publishes the GitHub
   release with the zip, `manifest.json(.sig)` and `framedrop.json`.

Until a key exists, in-app updates and `frameplayer-install` without
`--zip` refuse to install (they never accept unsigned manifests).
